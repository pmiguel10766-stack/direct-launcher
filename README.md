# DirectLauncher - Minecraft Java Edition

Um launcher moderno, leve e otimizado para o Minecraft Java Edition (focado na versão 1.7.10 e projetos personalizados), desenvolvido em Java Swing e empacotado com um instalador profissional em Inno Setup.

---

## 🚀 Funcionalidades

* **Interface Moderna e Limpa:** Design minimalista e intuitivo em tons de preto e azul.
* **Instalador Profissional:** Assistente gráfico com tema escuro, suporte a Português (Portugal), Português (Brasil) e Inglês, página de novidades da versão e termos de uso.
* **Download Automático:** O instalador descarrega a versão mais recente do launcher diretamente do GitHub.
* **Java 17 Opcional:** Podes instalar o Java 17 junto com o launcher, caso ainda não o tenhas.
* **Desempenho Otimizado:** Feito para correr de forma fluida em Java, integrando-se perfeitamente com ferramentas de modding e launchers personalizados.

---

## 📥 Instalação

1. Vai à secção de **Releases** do repositório.
2. Descarrega o ficheiro `DirectLauncher_Setup.exe`.
3. Executa o instalador no teu PC Windows e segue os passos do assistente:
   * Escolhe o idioma.
   * Escolhe se instalas para todos os utilizadores (`C:\Program Files\DirectLauncher`) ou só para o teu utilizador.
   * Lê e aceita os termos de uso.
   * Escolhe os componentes (DirectLauncher e, opcionalmente, Java 17).
4. Precisas de ligação à Internet, porque os ficheiros são descarregados durante a instalação.
5. Diverte-te a jogar!

---

## 🗑️ Desinstalação

Ao desinstalar, o programa pergunta se queres apagar também a pasta `.directlauncher` (contas, definições e jogos). O botão predefinido é **Não**, para não perderes os teus dados por engano.

---

## 🛠️ Tecnologias Utilizadas

* **Java Swing / AWT** (Interface Gráfica)
* **Launch4j** (Empacotamento do executável)
* **Inno Setup** (Criador do instalador moderno)

---

## ⚠️ Aviso

O DirectLauncher é um launcher não oficial e não é afiliado à Mojang Studios nem à Microsoft. É necessário possuir uma cópia legítima do Minecraft Java Edition.
