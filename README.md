#DirectLauncher - Minecraft Java Edition

Um launcher moderno, leve e otimizado para o Minecraft Java Edition (focado na versão 1.7.10 e projetos personalizados), desenvolvido em Java Swing e empacotado com um instalador profissional em Inno Setup.

---

## 🚀 Funcionalidades

* **Interface Moderna e Limpa:** Design minimalista e intuitivo em tons de preto e azul.
* **Instalador Profissional:** Assistente gráfico (`.isso`) com suporte multilíngue, atalhos automáticos e verificação de sistema.
* **Desempenho Otimizado:** Feito para correr de forma fluida em Java, integrando-se perfeitamente com ferramentas de modding e launchers personalizados.

---

## 📥 Instalação

1. Vai à secção de **Releases** do repositório.
2. Descarrega o ficheiro `DirectLauncher_Setup.iss`.
3. Executa o instalador no teu PC Windows e segue os passos do assistente.
4. Diverte-te a jogar!

---

## 🛠️ Tecnologias Utilizadas

* **Java Swing / AWT** (Interface Gráfica)
* **Launch4j** (Empacotamento do executável)
* **Inno Setup** (Criador do instalador moderno)
